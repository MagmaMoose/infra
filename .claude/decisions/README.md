# Architectural decisions

One file per decision: `YYYY-MM-DD-<topic>.md`. Write one when a choice is expensive to reverse
or when the next person would otherwise re-litigate it. Run `/adr`.

Tracked in git on purpose — `CLAUDE.md` lists this directory as load-on-demand context, and
headless agents clone this repo fresh, so a decision that stays on one machine is not a record.
